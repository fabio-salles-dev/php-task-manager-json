🚀 PHP Task Manager (JSON)

Sistema simples de gerenciamento de tarefas desenvolvido em PHP puro, com persistência em JSON.
Projeto focado em reforçar lógica de programação, manipulação de arrays e conceitos fundamentais de backend.

📌 Funcionalidades
➕ Adicionar tarefas
📋 Listar tarefas
✏️ Atualizar status (pendente/concluída)
❌ Remover tarefas
🔍 Buscar tarefas por nome
💾 Persistência de dados com JSON
🧠 Conceitos aplicados
Estruturas de dados com arrays
Controle de fluxo (if, foreach)
Manipulação de arquivos (file_get_contents, file_put_contents)
Serialização com json_encode e json_decode
Validação de dados
Simulação de CRUD (Create, Read, Update, Delete)
🛠️ Tecnologias
PHP 8+
JSON
▶️ Como executar
1. Clone o repositório
git clone https://github.com/fabio-salles-dev/php-task-manager-json
2. Acesse a pasta
cd php-task-manager-json
3. Execute no terminal
php index.php
🌐 Executar no navegador (recomendado)
php -S localhost:8000

Acesse:

http://localhost:8000
